# Customer Churn Prediction

## Project Overview

This project predicts customer churn using machine learning techniques. The objective is to identify customers who are likely to discontinue a service, enabling businesses to take proactive retention measures.

## Dataset

* Customer Churn Dataset
* Target Variable: Churn
* Classification Problem

## Tools & Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Project Workflow

1. Data Cleaning and Preprocessing
2. Feature Engineering
3. Data Scaling and Encoding
4. Model Training
5. Hyperparameter Tuning
6. Model Evaluation

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Skills Demonstrated

* Data Preprocessing
* Feature Engineering
* Classification Modeling
* Hyperparameter Tuning
* Model Evaluation
* Customer Analytics

## Conclusion

The project demonstrates how machine learning can be used to identify customers at risk of churn and support data-driven customer retention strategies.
